# Интернет-магазин с обработкой исключений (ДЗ 17.1)

Проект реализует базовые классы для интернет-магазина с обработкой исключений на Python.

## 📋 Реализованная функциональность

### 1. Класс Product (Товар)
- **Атрибуты**: `name`, `description`, `price`, `quantity`
- **Исключение**: `ZeroQuantityError` при `quantity == 0`
- **Строковое представление**: `"Название, цена руб. Остаток: количество шт."`
- **Метод `__repr__`**: для отладки

### 2. Класс Category (Категория)
- **Атрибуты**: `name`, `description`, приватный `__products`
- **Атрибуты класса**: `category_count`, `product_count`
- **Метод `add_product`**: добавление товара в категорию
- **Метод `average_price`**: расчет средней цены с обработкой `ZeroDivisionError`
- **Свойство `products`**: геттер для списка товаров
- **Строковое представление**: `"Название, количество продуктов: N шт."`

### 3. Исключение ZeroQuantityError
- Пользовательское исключение
- Наследуется от `ValueError`
- Сообщение: `"Товар с нулевым количеством не может быть добавлен"`
