# Проект: Интернет-магазин (E-commerce)

## Описание проекта
Проект интернет-магазина, реализованный на Python с использованием ООП.

## История разработки
1. ДЗ 14.1 - Создание классов Product и Category
2. ДЗ 14.2 - Режимы доступа, геттеры и сеттеры
3. ДЗ 15.1 - Магические методы (__str__, __add__)
4. ДЗ 16.1 - Наследование (Smartphone, LawnGrass)
5. ДЗ 16.2 - Абстрактные классы и миксины
6. ДЗ 17.1 - Обработка исключений (текущее задание)

## Структура веток
- main - основная стабильная ветка
- develop - ветка для разработки
- feature/* - ветки для новых функций
- homework/* - ветки для домашних заданий
