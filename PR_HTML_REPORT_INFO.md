## 📊 HTML ОТЧЕТ О ПОКРЫТИИ ТЕСТАМИ

### 🔧 Генерация отчета:
```bash
# Создать HTML отчет о покрытии
python -m pytest --cov=main --cov-report=html test_main.py

# После выполнения откройте в браузере:
# htmlcov/index.html
📈 Результаты отчета:
Общее покрытие: 97%

Тестов выполнено: 52 теста (все успешно)

Основной файл: main.py - полный отчет по строкам кода

Детализация: Покрытие каждого класса и метода

👁️ Визуализация в отчете:
🟢 Зеленые строки - полностью покрыты тестами

🔴 Красные строки - не покрыты тестами

🟡 Желтые строки - частично покрыты

📊 Процентные показатели для каждого файла
📁 Структура отчета:
htmlcov/
├── index.html          # Главная страница с общей статистикой
├── main_py.html        # Детальный отчет по main.py (покрытие по строкам)
├── class_index.html    # Отчет по классам
├── function_index.html # Отчет по функциям
└── *.css, *.js         # Стили и скрипты для отображения
🎯 Преимущества HTML отчета:
Наглядность - цветовая маркировка покрытия

Детализация - можно посмотреть покрытие каждой строки кода

Навигация - легко переходить между файлами и классами

Статистика - точные проценты покрытия

⚠️ Важно:
Отчет htmlcov/ не добавлен в репозиторий (уже в .gitignore)

Отчет можно сгенерировать в любой момент выполнения команды выше

Рекомендуется проверить отчет перед принятием PR

Для проверки: выполните команду генерации отчета и откройте htmlcov/index.html в браузере
