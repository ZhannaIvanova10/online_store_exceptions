# Интернет-магазин: Полная реализация ДЗ 14-17

Проект реализует полную систему интернет-магазина с обработкой исключений.

## 📚 Реализованные домашние задания

### **ДЗ 14.1: Базовые классы**
- Класс `Product` (Товар)
- Класс `Category` (Категория)

### **ДЗ 14.2: Приватные атрибуты и геттеры**
- Приватный атрибут `__products` в `Category`
- Property `products` для доступа к товарам
- Класс-метод `new_product()`

### **ДЗ 15.1: Магические методы**
- `__str__` для человекочитаемого представления
- `__add__` для сложения товаров (с проверкой типов)

### **ДЗ 16.1: Наследование**
- Класс `Smartphone` (Смартфон)
- Класс `LawnGrass` (Газонная трава)

### **ДЗ 16.2: Абстрактные классы и миксины**
- Абстрактный класс `BaseProduct`
- Миксин `ReprMixin` для единообразного `__repr__`

### **ДЗ 17.1: Обработка исключений**
- Пользовательское исключение `ZeroQuantityError`
- Обработка нулевого количества при создании товара
- Метод `average_price()` с обработкой `ZeroDivisionError`

## 🏗️ Архитектура
BaseProduct (абстрактный)
├── Product
│ ├── Smartphone
│ └── LawnGrass
└── ReprMixin (миксин)

├── products: List[Product]
