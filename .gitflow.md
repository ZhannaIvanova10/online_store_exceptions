# GitFlow для проекта интернет-магазина

## Основные ветки:
- main: стабильная версия, только релизы
- develop: текущая разработка

## Вспомогательные ветки:
- feature/*: новые функции
- bugfix/*: исправления багов
- release/*: подготовка релиза
- hotfix/*: срочные исправления
- homework/*: домашние задания

## Рабочий процесс:
1. Все разработки начинаются от develop
2. Завершенные задачи мержатся в develop
3. Релизы создаются от develop в release/*
4. После тестирования релиз мержится в main
